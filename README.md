# 香港大战僵尸2：生死存亡

独立于一代的新文件夹、新 Git 仓库。横版拔河 RTS，现代香港夜景，原创程序化像素角色与建筑；保留一代全部6文明、42兵种、18种文明技能，新增6文明、42兵种和18种技能。

## 运行

需要 Node.js 22+。打包使用 Node 内置 zlib，自动检查发行包中不含作者令牌。

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:4174 。单机不依赖平台登录、外部 CDN、图片下载或远程字体。

```powershell
npm test
npm run test:browser
npm run test:art
npm run test:interaction
npm run test:war
npm run build
```

浏览器验证默认使用本机 Microsoft Edge。其他环境可设置 `BROWSER_CHANNEL`；使用 Playwright Chromium 时可将测试启动项改为已安装的通道。测试截图保存在忽略的 `artifacts/`，发行包为 `dist/hkvsz2.zip`。

## 已实现

- 两个阵营均可操作；1v1、2v2、3v3、4v4；单人对AI，以及通过 GameHub 房间进行人人、人机混合对战。
- 原文明：中环金融中心、深水埗贫民窟、湾仔差馆、末日尸潮、港式怪谈、病毒实验体。
- 新人类文明：香港大学城、港氏野人帮、香港黑帮。
- 新僵尸文明：AI机器人僵尸、尸变体、非对称怪物。角色和基地为原创像素造型，不包含所提及商业作品的素材。
- 全部84个兵种都通过新像素骨架、装备与动作渲染；旧位图资源没有复制进本仓库。
- 四资源：食物、木头、黄金、石头；后方可见资源区；农民走到工作点后才产生收入。
- 开局8农民；普通文明50食物/16秒训练一名（大学城14秒，非对称怪物75食物/20秒）；农民与在训单位都预占人口。逐人直接改派，或在资源卡片上点击加减调配。
- 初始基地包含1座城镇中心和1座兵营，各提供1条串行训练队列。新增兵营（150木头/14秒）增加1条并行士兵队列；新增城镇中心（200木头+100石头/20秒）增加1条并行农民队列，均在农民施工完成后生效。
- 训练页逐条显示建筑、当前训练进度和等待订单；连续点击可排同种部队，默认按最早空闲时间分配，也可指定队列。每兵营最多12单，每城镇中心最多6单，入队时扣资源并预占人口；×取消订单全额退款、释放人口，后续订单自动前移。
- 士兵由所属兵营出场，农民由所属城镇中心出场；3v3/4v4所有单位、建筑、资源和采集农民统一映射到道路范围内，弹道与建筑点选共用落点规则。
- 民房消耗80木头，完工增加50人口；工坊提升采集效率；基地箭槽消耗80木头180石头，时代II解锁；炮槽消耗260石头160黄金，时代III解锁。防御槽安装在主基地上，分别双目标射击与范围轰炸。
- 后方资源区6个建设位，主基地另有2个防御槽；前线不再放置大型建筑。选建筑后点击战场或阵位按钮；工人自动施工、完成后恢复原采集任务。中途改派可以暂停并续建。
- 四个时代：升本使用食物与黄金，研究完成才解锁兵种并增加基地耐久。
- 低阶生物兵使用食物/木头，高阶生物兵使用食物/黄金，机械和攻城兵使用木头/黄金。
- AI使用同样的资源、人口、施工和科技规则，没有额外收入。
- 标准战和排位赛分别结算；本机档案、云端统计、成就、排行榜、对局历史；失败可重试云端保存。

## 美术与交互

`pixel.js` 是原创整数网格像素绘制器。独立处理步行、攻击、死亡、农民采集和施工姿态，按文明与兵种搭配服饰、武器、机械/有机轮廓。`renderer.js` 绘制香港天际线、楼宇、霓虹店招、街道、资源、基地、建筑施工、弹道和技能特效。音效通过 Web Audio 合成。

快捷键：1–7训练、W农民、B建筑、U升本、空格暂停、Esc取消放置。联机禁用暂停和倍速；单机切到后台自动暂停。手机页面支持操作与阵位按钮，战场在横屏更易看清。

## 联机实现

房主以30Hz运行仿真，把所有玩家及AI的合法动作安排到具体帧，每3帧广播一个有序批次。客户端只按房主批次推进。房间协议版本为6，与旧版本不同的客户端会提示刷新并重新建房；协议含会话编号和连续序列检查；远端动作的座位由平台发送者身份映射，忽略请求中伪造的座位。

准备室状态会合并，所有玩法/大厅写入按75ms间隔发送，低于平台20条/秒限制；不传全量实体快照。掉线玩家的基地退出，队友继续；房主掉线、12秒无同步或帧序列异常则中止且不结算排位。暂不支持中途加入、断线重连、房主迁移及全服自动匹配队列。

GameHub是房间转发服务。胜负和胜点由客户端上报，适合当前平台的好友/社区对战；严格竞技防作弊需要另建权威游戏服务器。这是平台边界，当前没有宣称服务端验证战果。

## 部署到 GameHub

```powershell
npm run build
$env:GAMEHUB_TOKEN = '在当前进程中设置作者令牌'
node scripts/deploy.mjs --check
node scripts/deploy.mjs
```

脚本先核验账号、按精确标题找项目。首次建立独立的第二代游戏，后续给同名项目增加版本，并配置 `src/gamehub.progression.json`。公开项目/版本信息写入 `deployment.json`；令牌只从进程环境读取，不会写入文件或发行包。平台游玩需要使用玩家自己的登录会话。

## v0.5.4 纯AI召唤与受保护的基地重建

- 纯AI队伍可在原有10%全队耐久阈值下自动召唤战争巨兽。首名未退出AI提出选择，全队仍只有一次机会；混合队伍的选择权留给真人。
- 废墟需要由农民修满100%才恢复运作。修复期间从普通部队、巨兽和技能的基地索敌中排除，伤害入口也拒绝命中；在途轰炸不能打断重建。正常存活基地的日常维修仍可受到攻击。
- 重建按满血显示进度并标明保护中。重建基地仍属于失守状态，队伍必须保住另一座运作基地或传送门才能继续救援，避免仅有不可攻击废墟时无法结束对局。

## v0.6.0 本地单局回放

- 游戏自动录制开局随机种子、配置、所有真人/AI实际执行成功的指令及其30Hz仿真帧、同帧顺序；不保存逐单位逐帧同步数据。支持正常结束、游戏内离开及联机中止片段。
- 作战中心顶部「单局回放」是独立入口，结算页也可「观看本局回放」。本浏览器的IndexedDB保留最近5场，刷新可继续查看，超出后自动清理最早记录；浏览器不允许持久化时退回当前页面内存缓存。回放不上传服务器，换设备或清理浏览器数据后不保留；可导出JSON文件备份、导入观看。
- 支持暂停/空格继续、0.5/1/2/4/8/16倍速、时间轴跳转、从头播放、切换任意玩家视角查看经济与部队。回放只读，不提交作战输入、不重新运行AI、不写入战绩/胜点/成就/排行榜。
- 终点使用状态校验核对还原结果，忽略仅用于AI决策节拍的last_ai_think元数据。倒退和跳转在内存保留最多12个30秒检查点，分批仿真，避免定位时堵住界面；检查点不写入回放文件。
- 记录绑定实际游戏版本，后续版本从本机记录跳到录制版本的既有静态入口播放，避免平衡调整影响旧局。旧版游戏未录制的历史不能补录；旧资源被删除时需要保留兼容版本。文件格式/指令字段/帧序/长度有校验，文件最大16 MiB、最长6小时/25万条指令。
- `npm run test:replay` 验证录制/重放、进度定位、只读、零二次结算、最近5场、刷新后持久化、导出导入、临时缓存、390px手机界面以及真实SDK双客户端指令回放。
