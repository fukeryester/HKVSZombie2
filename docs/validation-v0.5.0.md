- 建造所有资源成本2倍，保留野人帮住房25%折扣；时代II/III/IV采用3/3.5/4倍费用：900食540金、2625食1575金、5600食3600金。

## 战争巨兽

- 阈值按全队当前基地耐久之和/最大耐久之和计算，<=10%且仍未判负时可选择。任何未退出真人（包括单座基地失守者）均可确认；AI、错阵营、第二次选择、重复点击及竞争失败均由仿真拒绝。弹窗打开不锁名额，首次合法确认才锁定全队唯一机会，巨兽死亡不退款次数。
- 飞艇120000生命：过滤近战目标/伤害；延迟空对地AOE炸弹，飞行与落地伤害时间一致。
- 列车5节×16000生命：五个独立加特林，往返轨道，按攻击位置选择受损车厢；车厢阵亡后模型与碰撞体缩短。全局百分比伤害按各存活车厢自身最大生命结算。

- 传送门100000生命：每秒从6个僵尸文明所有一至三阶兵随机产生3–5名专属援军；援军不受普通人口限制，兵种文明/模板随快照保存。
- 僵尸王30000生命：所有普通/真实/百分比伤害逐次最多1点；范围普通敌军被强制杀死并重生为随机一至三阶僵尸；战争巨兽不被转化，仍承受普通近战伤害。
