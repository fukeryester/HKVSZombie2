# v0.2.0 验证记录

日期：2026-10-23（Asia/Shanghai）。

## 并行训练

- 初始基地提供1条兵营队列和1条城镇中心队列。每座新增建筑完工后，分别增加一条独立串行队列；队列间并行。
- 兵营：150木头，施工14秒；城镇中心：200木头与100石头，施工20秒。施工时间不含农民步行。
- 连续点击同一兵种可排队，移除旧版按兵种限制的点击冷却。默认选最早空闲的队列，也可指定某座建筑。
- 入队预扣资源并预占人口；取消当前或等待订单均全额返还，释放人口，只重排所属队列。其他队列的进度不变。
- 不同队列的到期订单独立完成，较早插入的长训练不会阻塞另一兵营的短训练。
- 士兵和农民分别从对应兵营、城镇中心位置出场。
- UI逐条显示建筑、训练进度、剩余时间、等待订单和取消入口。

## 道路落点

- 移除旧版按玩家row向上偏移36像素的渲染方式；四排落点统一位于现有道路内。
- 主基地、建筑、资源区、士兵、农民、尸体、投射物和建筑放置区域使用统一道路投影。
- 建筑阵位沿基地朝战线方向展开，每格间隔60像素，避免新建筑被主基地遮挡。
- 3v3与4v4的士兵、农民落点检查通过；另以浏览器截图检查实际道路位置。跳跃、飞行单位和抛物线仍保留对应动作。

## 验证结果

- `npm test`：29项全部通过，含新增并行训练、取消退款、容量限制、非法建筑队列、出场点和3v3/4v4道路投影检查。
- `npm run test:browser`：菜单、两阵营、建筑完工、多队列、连续点击、指定队列、进度、取消、人口与资源UI、手机布局全部通过，无运行时异常。
- 8个隔离浏览器会话通过真实SDK连接模拟平台转发服务。各端完成兵营、城镇中心建造、并行训练以及远端取消订单；第948帧完整状态逐字段一致。最大消息1229字节，发送频率不超过20条/秒。
- 模拟转发测试在共同仿真帧设置一致的资源夹具，建造、训练和取消均通过正常网络动作完成；不等同于8名不同真实账号的公网测试。
- 真实平台双端测试通过：双方各建造第二座兵营和第二座城镇中心，实际采集并支付资源，两类队列均并行运行；第1488帧完整状态一致。未提交测试战绩或排位分数。
- 房主掉线和非房主掉线行为保持正确。
- 网络协议升至3，旧版客户端收到不同协议时提示刷新并重新建房。
